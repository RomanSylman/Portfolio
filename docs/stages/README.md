# Stage log

Each stage records its goal, what landed, the decisions behind it and how to
verify the result.

- [Stage 01: Foundation](01-foundation.md) sets up the framework, strict typing
  and the quality toolchain.
- [Stage 02: Architecture and internationalization](02-architecture.md) lays down
  Feature-Sliced Design and bilingual routing.
- [Stage 03: Scroll tracking and the shared WebGL canvas](03-scroll-and-webgl.md)
  adds smooth scrolling and the single WebGL context.
- [Stage 04: Scene, sections and case studies](04-scene-and-content.md) builds the
  particle scene, the page sections and the MDX case studies.
- [Stage 05: Automation and documentation](05-automation-and-docs.md) adds CI and
  the documentation set.
- [Stage 06: Wow pass](06-wow-pass.md) fixes pointer, stage and screenshot bugs
  and adds the intro, text motion, glow, cursor and scene placement.
